# Mosaic Tech

> Mosaic Tech (Mosaic) was a San Francisco-based Strategic Finance Platform, founded in 2019, that
> connected ERP, CRM, HRIS, billing and data-warehouse systems into a single financial data model for
> FP&A teams. HiBob acquired Mosaic on 2025-02-13 (closed 2025-04-01) and folded the product into its
> finance/FP&A suite. As of 2026-08-26 the Mosaic brand is absorbed and Mosaic operates no public API.

## Status

- Company status: absorbed into HiBob (acquisition announced 2025-02-13, closed 2025-04-01).
- mosaic.tech and www.mosaic.tech 301-redirect every path to hibob.com.
- app.mosaic.tech 301-redirects to https://finance-app.hibob.com/.
- api.mosaic.tech returns HTTP 503 on every path probed (2026-08-26).
- docs., developer., developers., status., help. and support.mosaic.tech do not resolve.
- trust.mosaic.tech is the only Mosaic-branded surface still live.

## API surface

Mosaic Tech publishes no public API. There is no OpenAPI, AsyncAPI, GraphQL SDL, WSDL, .proto,
MCP server, A2A agent card, SDK, CLI or developer portal under the mosaic.tech domain, and none was
found in the Internet Archive's 493 recorded mosaic.tech URLs. Third-party research reaches the same
conclusion (Stitchflow, "Mosaic does not publish a public REST API or developer documentation").

If you are looking for a callable API for this product today, it is HiBob's, not Mosaic's:
https://apidocs.hibob.com/ — profiled separately at https://apis.io/providers/hibob/.
